# Replaceable application logos

`mudernize-logo.svg` is the current placeholder for the MUDernize brand. Replace
it with official square artwork while keeping the filename to update both the
login header and dashboard sidebar automatically.

The batch logo slots use `sanghaya.png`, `astraea.png`, `solaris.png`, and
`slcn-logo.png`. Square transparent PNG or SVG artwork works best. These files
appear in the login category selector and beside the active batch in the
sidebar. No database change is required.

The interface uses Libre Baskerville for page headings and Manrope for controls,
body text, and numerical data. Both are self-hosted by Next.js at build time.
